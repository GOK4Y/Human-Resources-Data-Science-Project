# 🧑‍💼 Human Resources Data Science Project

Bu proje, bir insan kaynakları veri seti üzerinde çalışan memnuniyeti ve çalışan kaybı (attrition) gibi konuları analiz ederek, **çalışan davranışlarını tahmin etmek** amacıyla makine öğrenmesi yöntemleri uygulamaktadır.

## 📊 Proje Amacı

- İnsan kaynakları verilerini analiz ederek öngörücü modeller oluşturmak
- Çalışan memnuniyetini ve işten ayrılma eğilimlerini anlamak
- Farklı makine öğrenmesi algoritmalarının performanslarını karşılaştırmak

## 🧠 Kullanılan Yöntemler

- **Veri Temizleme ve Hazırlama**
- **Keşifsel Veri Analizi (EDA)**
- **Öznitelik Seçimi (Feature Selection)**
- **Modelleme:**
  - Logistic Regression
  - Random Forest
  - Yapay Sinir Ağı (Keras ile)
- **Model Değerlendirme:**
  - Accuracy, Precision, Recall, F1 Score
  - Confusion Matrix
  - ROC Curve

## 🛠️ Kullanılan Teknolojiler

- Python (pandas, numpy, scikit-learn, keras, matplotlib, seaborn)
- Google Colab
- Jupyter Notebook

## 📁 Dosya Yapısı

| Dosya | Açıklama |
|-------|----------|
| `Human_Resources_Department_Skeleton_adlı_not_defterinin_kopyası.ipynb` | Projenin ana Jupyter defteri. Tüm veri analiz ve modelleme adımları burada yer alır. |

## 🔍 Veri Kümesi

Veri seti, çalışanlara ait yaş, eğitim, maaş, departman, memnuniyet gibi çeşitli demografik ve mesleki bilgileri içerir. Bu veri seti aracılığıyla çalışanların işten ayrılma olasılıkları tahmin edilmeye çalışılmıştır.

## 🚀 Nasıl Kullanılır?

1. [Google Colab](https://colab.research.google.com) üzerinden notebook'u açın.
2. Gerekli kütüphaneleri yükleyin (`pip install` gerekli olabilir).
3. Hücreleri sırasıyla çalıştırarak analiz sürecini takip edin veya tüm hücreleri tek seferde çalıştırmak için:
Runtime > Run all

## 📈 Model Performansı

Model sonuçları `Testing Set Performance` kısmında değerlendirilmiştir. Burada test verisi üzerinde alınan başarı metrikleri yer alır ve modelin genelleme yeteneği ölçülür.
